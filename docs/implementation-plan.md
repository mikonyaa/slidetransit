2. Build read-only manifest/PPTX/PDF pipeline and test coordinate canaries.
3. Compare independent text, geometry and raster evidence; preserve ambiguity.
4. Deliver an offline responsive reviewer, revision-bound decisions and CLI.
5. Test bounded hostile inputs, real fixtures, browser controls and final consumers.
6. Audit staged sources and packages, create public repository, verify exact-commit CI.
7. Publish those CI-built bytes, verify anonymous install, deploy and check static demo.

numbered evidence rails and paired crops are the recognition anchor. DFII 15
(impact 4, fit 5, feasibility 5, performance 5, consistency risk 4).
