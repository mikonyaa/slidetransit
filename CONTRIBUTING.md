# Contributing

Use Python 3.13 and the committed uv lock. Run the development commands in the README.
Keep parsing, measurement, comparison, review and presentation separate. A new rule
needs a measured fixture, a documented threshold and an honest uncertainty boundary.
Change the rule version when behavior changes; input/configuration/implementation
fingerprints must invalidate previous decisions. Preserve the no-upload default.

Submit only your own or explicitly authorized test materials. Label genuine exports
and synthetic unit PDFs distinctly. Never include personal slides, access tokens,
commercial font binaries, private paths or fabricated exporter provenance.

The public API is experimental in 0.1. Schema changes require a new schema version.
